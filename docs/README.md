# Documentación de English Fast

Esta carpeta organiza la documentación de producto de English Fast sin reemplazar el `README.md` principal del repositorio.

## Estado

**MVP web funcional en desarrollo activo.**

La aplicación ofrece actualmente dos rutas guiadas —Vocabulario y Gramática— con contenido A1 y A2 inicial, progreso local por ejercicio, repaso de errores, cinco recursos educativos públicos e integración con el núcleo compartido de accesibilidad de Neuronova Apps.

## Documentos

- [`ALCANCE.md`](ALCANCE.md): define qué forma parte del MVP actual, qué está fuera de alcance y qué funcionalidades permanecen futuras.
- [`ROADMAP.md`](ROADMAP.md): ordena las siguientes etapas de desarrollo y sus prioridades.

## Fuente de verdad

Para el estado funcional actual, esta documentación debe mantenerse alineada con:

- `README.md`;
- `index.html`;
- `content.js`;
- `script.js`;
- `feedback.js`;
- `exercise-accessibility.js`;
- las cinco páginas educativas públicas;
- `sitemap.xml`.

Cuando una función pase de futura a disponible, deben actualizarse en el mismo cambio al menos `README.md`, `docs/ALCANCE.md` y `docs/ROADMAP.md` cuando corresponda.
